# May tinh co ban bang PyQt5

Day la ung dung may tinh bo tui don gian duoc viet bang Python va PyQt5.
Phan tinh toan su dung `if/elif`, khong dung `eval()`.

## Tinh nang

- Cong, tru, nhan va chia
- Nhap so nguyen va so thap phan
- Doi dau so bang nut `+/-`
- Xoa mot ky tu bang nut `<-`
- Xoa toan bo bang nut `C`
- Hien `Error` khi chia cho 0
- Ho tro ban phim

## Phim tat

| Phim | Chuc nang |
|---|---|
| `0-9` | Nhap so |
| `+ - * /` | Chon phep tinh |
| `Enter` hoac `=` | Tinh ket qua |
| `Backspace` | Xoa mot ky tu |
| `Esc` | Xoa toan bo |

## Cai dat

Tu thu muc goc cua du an, chay:

```bash
pip install -r requirements.txt
```

## Chay chuong trinh

```bash
python3 handcoded/calculator.py
```

Yeu cau Python 3.8 tro len.
